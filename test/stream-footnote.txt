# Streaming Footnotes

Tests for streaming-mode footnote ref/def behavior.
Streaming unlinks refs from defs: all [^label] refs emit
FOOTNOTE_REF callbacks during feed, and all definitions
emit FOOTNOTE_DEF at flush time, in definition order.

The test binary is stream-event --footnotes.


## Orphan ref — ref with no matching definition

```````````````````````````````` example
[^orphan]
.
6 events
+BLOCK   DOC
+BLOCK   P
>SPAN    FOOTNOTE_REF  {label="orphan"}
<SPAN    FOOTNOTE_REF
-BLOCK   P
-BLOCK   DOC
````````````````````````````````


## Ref before def — ref fires during feed, def at flush

```````````````````````````````` example
[^x]

[^x]: footnote body
.
11 events
+BLOCK   DOC
+BLOCK   P
>SPAN    FOOTNOTE_REF  {label="x"}
<SPAN    FOOTNOTE_REF
-BLOCK   P
+BLOCK   FOOTNOTE_DEF_SECTION
+BLOCK   FOOTNOTE_DEF  {label="x"}
TEXT  "footnote body"  (NORMAL)
-BLOCK   FOOTNOTE_DEF
-BLOCK   FOOTNOTE_DEF_SECTION
-BLOCK   DOC
````````````````````````````````
