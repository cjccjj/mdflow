# Streaming Reference Links and Images

Tests for streaming-mode reference link/image behavior.
All [text][ref], [text][], [text], ![alt][ref] syntax
is emitted as REF_LINK/REF_IMAGE hints during feed.
Definitions are emitted as a REFERENCE_SECTION at flush, with one
REFERENCE_DEF block carrying label, destination, and optional title details.

The test binary is stream-event (no flag).


## Reference image with matching definition

```````````````````````````````` example
![alt][img]

[img]: /url.png
.
11 events
+BLOCK   DOC
+BLOCK   P
>SPAN    REF_IMAGE  {label="img"}
TEXT  "alt"  (NORMAL)
<SPAN    REF_IMAGE
-BLOCK   P
+BLOCK   REFERENCE_SECTION
+BLOCK   REFERENCE_DEF  {label="img", dest="/url.png", title=""}
-BLOCK   REFERENCE_DEF
-BLOCK   REFERENCE_SECTION
-BLOCK   DOC
````````````````````````````````

## Definition fields are structured

```````````````````````````````` example
[uri]: https://example.com/docs "remote"
[section]: #intro
[file]: docs/readme.md
.
10 events
+BLOCK   DOC
+BLOCK   REFERENCE_SECTION
+BLOCK   REFERENCE_DEF  {label="uri", dest="https://example.com/docs", title="remote"}
-BLOCK   REFERENCE_DEF
+BLOCK   REFERENCE_DEF  {label="section", dest="#intro", title=""}
-BLOCK   REFERENCE_DEF
+BLOCK   REFERENCE_DEF  {label="file", dest="docs/readme.md", title=""}
-BLOCK   REFERENCE_DEF
-BLOCK   REFERENCE_SECTION
-BLOCK   DOC
````````````````````````````````


## Multiline label and title details

```````````````````````````````` example
[
multi
label
]: /docs/file.md '
line one
line two
'
.
6 events
+BLOCK   DOC
+BLOCK   REFERENCE_SECTION
+BLOCK   REFERENCE_DEF  {label="multi label", dest="/docs/file.md", title="\nline one\nline two\n"}
-BLOCK   REFERENCE_DEF
-BLOCK   REFERENCE_SECTION
-BLOCK   DOC
````````````````````````````````
