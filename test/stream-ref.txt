# Streaming Reference Links and Images

Tests for streaming-mode reference link/image behavior.
All [text][ref], [text][], [text], ![alt][ref] syntax
is emitted as REF_LINK/REF_IMAGE hints during feed.
Definitions are emitted as a REFERENCE_SECTION at flush.

The test binary is stream-event (no flag).


## Reference image with matching definition

```````````````````````````````` example
![alt][img]

[img]: /url.png
.
15 events
+BLOCK   DOC
+BLOCK   P
>SPAN    REF_IMAGE  {label="img"}
TEXT  "alt"  (NORMAL)
<SPAN    REF_IMAGE
-BLOCK   P
+BLOCK   REFERENCE_SECTION
TEXT  "["  (NORMAL)
TEXT  "img"  (NORMAL)
TEXT  "]:"  (NORMAL)
TEXT  " "  (NORMAL)
TEXT  "/url.png"  (NORMAL)
TEXT  "\n"  (NORMAL)
-BLOCK   REFERENCE_SECTION
-BLOCK   DOC
````````````````````````````````


## Reference link with matching definition

```````````````````````````````` example
[text][ref]

[ref]: /url
.
15 events
+BLOCK   DOC
+BLOCK   P
>SPAN    REF_LINK  {label="ref"}
TEXT  "text"  (NORMAL)
<SPAN    REF_LINK
-BLOCK   P
+BLOCK   REFERENCE_SECTION
TEXT  "["  (NORMAL)
TEXT  "ref"  (NORMAL)
TEXT  "]:"  (NORMAL)
TEXT  " "  (NORMAL)
TEXT  "/url"  (NORMAL)
TEXT  "\n"  (NORMAL)
-BLOCK   REFERENCE_SECTION
-BLOCK   DOC
````````````````````````````````
