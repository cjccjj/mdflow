# Golden output tests for the ANSI renderer.
#
# Each example: markdown, '.', expected output.
#
# Expected output is a contract with the DEFAULT THEME. Two comparison
# modes (see test/run-render-tests.py):
#   - expected containing '␛' (U+241B) → exact byte-for-byte ANSI match;
#     ␛ is the ESC byte
#   - otherwise → SGR codes are stripped and the visible text must match
#
# The CLI epilogue (trailing newline + SGR reset) is stripped by the
# runner and must NOT appear here.
#
# Change the theme or renderer output → update these deliberately.
